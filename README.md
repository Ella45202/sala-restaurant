# SALA — Modern Thai Kitchen

A modern Thai fine-dining restaurant website designed to provide an elegant and user-friendly online experience.

## About the Project

SALA is a restaurant website project built to practice frontend development, backend development, database integration, and UI/UX design.

The website features a modern visual style inspired by contemporary fine dining, using warm neutral colors, elegant typography, and food photography.

## Features

- Responsive restaurant website design
- Interactive menu and food categories
- Restaurant story and dining experiences pages
- Table reservation form
- Customer contact form
- Email notifications using Resend
- Backend API built with Express.js
- MySQL database integration for reservations and contact messages

## Getting Started

### Prerequisites

- Node.js and npm
- MySQL Server
- A local database named `sala_restaurant`

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ella45202/sala-restaurant.git
   ```

2. Open the project folder:

   ```bash
   cd sala-restaurant
   ```

3. Install the backend dependencies:

   ```bash
   cd backend
   npm install
   ```

4. Configure your environment variables in a local `.env` file. Do not commit this file to GitHub.

   Required configuration includes your Resend API key and notification email settings. Configure your MySQL connection using the `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, and `DB_PORT` variables.

5. Make sure your local MySQL server is running and the database and required tables have been created.

6. Start the backend:

   ```bash
   npm start
   ```

7. Open `http://localhost:3000` in your browser.
